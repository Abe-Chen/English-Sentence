## 1. 产品定位与目标

### 1.1 产品定位

English Sentence 是一款基于电影素材的英语学习 App。用户可以导入本地英语电影视频，App 会自动提取其中的台词音频并生成一个专辑：每部电影对应一个专辑，每句台词对应一首“歌曲”，台词文本即歌词。通过将电影对话拆解成可听、可读、可跟读的单元，用户可以在熟悉的“专辑 → 曲目 → 歌词”结构中获得沉浸式学习体验。

### 1.2 核心目标

- 最大化复用现有音乐 App 架构，最小化改动成本；
- 保留专辑、播放、循环、后台播放等音乐播放器基础功能；
- 新增“从视频生成专辑”的能力；
- 让英语学习行为自然融入听专辑的交互习惯中。

---

## 2. 主要用户场景

| 场景 | 描述 |
| --- | --- |
| 导入电影 | 用户选择本地电影文件（MP4/MKV），App 自动提取音频与字幕。 |
| 生成专辑 | 系统根据电影标题创建一个新专辑，台词被拆成多个音频轨道。 |
| 听台词 | 用户可像听歌一样播放、循环、收藏任意一句台词。 |
| 看字幕 | 每句台词作为歌词显示，并支持同步滚动。 |
| 跟读模仿 | 用户可以重复播放一句台词（单句循环）并进行跟读练习。 |
| 复习专辑 | 用户可快速回顾整部电影的所有台词，强化听力与语感。 |

## 3. 核心功能说明

### 3.1 功能总览

| 模块 | 功能 | 说明 |
| --- | --- | --- |
| 专辑模块 | 保留原有音乐专辑结构 | 每部电影 = 一个专辑 |
| 曲目模块 | 台词音频作为“曲目” | 每句台词 = 一首歌 |
| 歌词模块 | 显示台词文本 | 每首歌的歌词 = 台词文本 |
| 视频导入 | 选择电影文件、提取音频、切分字幕 | 新增功能 |
| 音频生成 | 按台词生成音频片段并打标签 | 新增功能 |
| 播放功能 | 播放、单曲循环、后台播放、倍速播放 | 复用基础能力并适配学习场景 |
| 专辑识别 | “Dialog Study” 专辑标识 | 区分学习专辑与普通音乐专辑 |
| 数据持久化 | 保存导入记录 | 使用 Room 数据库或系统媒体库 |
| 导出功能（可选） | 导出生成音频 | 可生成 MP3 文件用于外部播放 |

### 3.2 导入电影视频

- 通过 SAF 文件选择器导入本地视频（MP4/MKV）。
- 若视频内嵌英文字幕，自动提取；若无字幕，允许手动选择 `.srt` 文件。
- 提取音轨（单声道、16kHz）用于后续切分处理。

### 3.3 台词切分与音频生成

- 基于字幕时间轴将音频切分为多个片段。
- 每个片段对应一句台词，自动生成音频文件：
  ```
  /Music/EnglishDialog/MovieTitle/001_I'm_fine_thanks.m4a
  ```
- 为每个文件写入元数据：
  - `ALBUM` = 电影名
  - `ALBUM_ARTIST` = Dialog Study
  - `GENRE` = DialogStudy
  - `TITLE` = 台词内容（必要时截断）
  - `TRACK` = 序号（001、002、003...）
- 调用 `MediaScannerConnection.scanFile` 更新系统媒体库。
- App 自动检测新专辑并展示。

### 3.4 专辑展示与标识

- 保留原“专辑”模块 UI。
- 若专辑的 `albumArtist == "Dialog Study"`，在右上角显示“学习”角标。
- 新增“仅显示学习专辑”筛选开关。

### 3.5 曲目与歌词显示

- 每句台词即一首曲目。
- 曲目名展示台词内容或前半句。
- 歌词区域显示完整字幕文本，并支持自动滚动。

### 3.6 播放功能

- 播放模式：整张专辑 / 单句播放 / 单曲循环。
- 保留 Auxio 的后台播放和通知栏控制能力。
- 可选增强：倍速播放（0.8x ~ 1.5x）。

### 3.7 数据存储

- 使用系统媒体库管理生成文件。
- 同步写入本地数据库以加速展示与索引。

### 3.8 后续可扩展功能（Roadmap）

| 功能 | 说明 |
| --- | --- |
| 静音切分 | 无字幕视频自动分句 |
| 语音识别 | Whisper 识别自动生成台词文本 |
| 跟读模式 | 用户录音与原音对比 |
| 云同步 | 电影学习进度同步 |
| 导出复习包 | 导出整部电影的音频与字幕 |

## 4. 信息架构与数据结构

### 4.1 目录结构

```
/Music/EnglishDialog/<MovieTitle>/
 ├── 001_Hello_there.m4a
 ├── 002_How_are_you.m4a
 ├── album.json
 └── cover.jpg
```

### 4.2 `album.json` 示例

```json
{
  "album": "Forrest Gump",
  "albumArtist": "Dialog Study",
  "genre": "DialogStudy",
  "tracks": [
    {
      "track": 1,
      "startMs": 1234,
      "endMs": 3420,
      "title": "My mom always said life was like a box of chocolates.",
      "path": "001_My_mom_always_said.m4a"
    }
  ]
}
```

## 6. 性能与约束

- 生成过程中使用前台服务，防止系统杀进程；
- 处理 2 小时视频需在 10 分钟内完成（视设备性能而定）；
- 输出音质在音质与体积间平衡（推荐 AAC 64 ~ 128 kbps）；
- 支持离线使用，无需联网。

## 7. 兼容与依赖

- **最低兼容版本**：Android 8.1+
- **JDK 要求**：JDK 17
- **关键依赖**：
  - FFmpegKit-Android（音频提取与分割）
  - Room / MediaStore（数据管理）
  - Kotlin Coroutines（异步任务）
  - Jetpack Compose（UI）

## 10. 总结

English Sentence 的核心设计理念是在不重造轮子的前提下，将音乐播放器的成熟体验延伸到英语学习场景。通过电影素材驱动的“专辑 → 曲目 → 歌词”结构，用户可以像听音乐一样沉浸式地学习电影台词，实现“听、读、跟读”一体化的高频练习流程。
